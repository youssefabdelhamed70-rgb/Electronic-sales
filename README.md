# Electronic-sales
المبيعات معتمدة بشكل أساسي على السوشيال ميديا، والخصومات مش العامل الرئيسي، لكن الجودة وعدد القطع هما اللي بيأثروا أكتر على القرار الشرائي.
المشكلة
إدارة المبيعات عايزة تفهم:
•	أنهي منتجات وقنوات بتجيب أعلى مبيعات؟
•	ليه في مرتجعات كتير؟
•	هل الخصومات فعلًا بتزود المبيعات ولا لأ؟

•	نحسن استراتيجية التسويق والخصومات
